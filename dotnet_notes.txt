*Reading User Input from the Console
Use Console.ReadLine() to capture text entered by the user.

Console.Write("Enter your name: ");
string name = Console.ReadLine();
Console.WriteLine($"Hello, {name}! Welcome to C#.");




*Working with Command-Line Arguments
In modern .NET console apps, an args array is automatically available globally. You can pass values when running your app from the terminal.


Parsing and Converting User Input (Numbers and Dates)
Since Console.ReadLine() always returns a string, you need to parse it to convert it into numbers or dates. Using TryParse is best because it prevents your program from crashing if the user types invalid input.

csharp_basics/                 ← your project folder (made by `dotnet new console`)
    ├── Program.cs                 ← YOUR CODE
    ├── csharp_basics.csproj       ← project settings
    ├── obj/                       ← temporary build files (auto-generated)
    └── bin/                       ← final runnable output (auto-generated)
	
	
	
obj/: the build's scratch work (auto-generated, don't touch)

bin/Debug/net10.0/: your finished app (auto-generated)


Key points
You only edit Program.cs and sometimes the .csproj.
bin/ and obj/ are rebuilt every time you run dotnet build or dotnet run. You can safely delete them.
Debug is the default build mode. dotnet build -c Release puts an optimized build in bin/Release/.
